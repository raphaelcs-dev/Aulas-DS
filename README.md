# Aulas-DS
Repositório com o objetivo de armazenar arquivos de exercícios e aulas da matéria Desenvolvimento de Sistemas. Onde tem o foco em Java, onde exploramos os pilares da Orientação a Objetos. 

## Exercícios
Os exercícios estão organizados em códigos exemplos passado pelo professor, e depois tem vários exercícios que temos que resolver. Tudo isso é feito em aula
